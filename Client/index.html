myScheme Accessibility Audit

Website accessibility testing and documentation

Project Overview

This project documents accessibility observations from a manual keyboard audit and a Lighthouse review of myScheme.

Audit documentation

Audit Findings

  • Keyboard navigation and focus order
  • Language selector keyboard accessibility
  • Search field color contrast
  • Footer links keyboard accessibility
  • Accessibility widget keyboard focus

Testing Checklist

  • Test interactive controls using the keyboard.
  • Check visible focus indicators.
  • Review text and background contrast.
  • Check navigation order and labels.

These are audit areas, not claims that every issue has been fixed.
