
# Manual Accessibility Test Checklist

## Keyboard Navigation
- [ ] Navigate using Tab and Shift+Tab.
- [ ] Confirm focus is visible on interactive controls.
- [ ] Use Enter or Space to activate controls where appropriate.
- [ ] Check that focus order is logical.

## Language Selector
- [ ] Reach the language selector using the keyboard.
- [ ] Open the language menu using the keyboard.
- [ ] Select a language and verify the result.

## Search Field
- [ ] Reach the search field using the keyboard.
- [ ] Enter a scheme name and submit the search.
- [ ] Check placeholder text contrast.

## Footer Links
- [ ] Test Quick Links using the keyboard.
- [ ] Test Useful Links using the keyboard.
- [ ] Check visible focus indicators.

## Accessibility Widget
- [ ] Reach the floating widget using the keyboard.
- [ ] Open and operate it without a mouse.

## Results
Record Pass, Fail, or Not Tested for each item after testing.
