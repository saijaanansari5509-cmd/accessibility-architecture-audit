# Accessibility Architecture Audit

## Project Overview
This project documents an accessibility audit of the myScheme website.

## Audit Findings
- Keyboard navigation and focus order
- Language selector keyboard accessibility
- Search field color contrast
- Footer links keyboard accessibility
- Accessibility widget keyboard focus

## Project Structure
- client/ - Frontend application
- server/ - Backend services
- docs/ - Project documentation
- test/ - Testing documentation
